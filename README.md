# برنامج جمعية آيات الخيرية — إدارة حلقات تحفيظ القرآن الكريم

نسخة مبنية على أحدث إصدار من برنامج تراث، بهوية آيات.

- قاعدة البيانات: مشروع Supabase باسم `Ayat-app` (الهيكل في `supabase/schema.sql`).
- التبرع: صفحة `donate.html` تفتح مشروع "أهل الله" في موقع آيات.
- الحاويتان `civil-ids` و`student-photos` عامتان لأن البرنامج يحفظ روابط عامة للصور.
